# GPA Planner (App giữa kỳ)

Ứng dụng Android tính GPA từ điểm thành phần theo quy chế tín chỉ, và lập kế hoạch học tập để đạt GPA mục tiêu.

## Tải về

**[Tải GpaPlanner.apk (bản mới nhất)](https://github.com/NguyenDuyTu275/app-giua-ky-release/releases/latest/download/GpaPlanner.apk)**

Xem tất cả phiên bản tại [Releases](https://github.com/NguyenDuyTu275/app-giua-ky-release/releases).

## Cài đặt

1. Mở link tải ở trên bằng trình duyệt trên điện thoại Android (Android 8.0 trở lên).
2. Mở file `GpaPlanner.apk` vừa tải về.
3. Nếu máy hỏi, cho phép trình duyệt "Cài ứng dụng không rõ nguồn", rồi bấm **Cài đặt**.
4. Google Play Protect có thể cảnh báo vì app không tải từ CH Play: chọn **Vẫn cài đặt**.

## Tính năng

- **Tổng quan**: GPA tích lũy hệ 4 và hệ 10, xếp loại, biểu đồ GPA theo kỳ, phân bố điểm chữ
- **Bảng điểm**: nhập điểm thành phần theo học kỳ, xuất/nhập file Excel
- **Kế hoạch**: các kỳ sau cần đạt bao nhiêu để lên GPA mục tiêu, "cứu môn", giả lập học cải thiện
- **Chương trình**: tiến độ tín chỉ và cây môn học theo kỳ
- **Cố vấn AI**: hỏi đáp học vụ và lập lịch ôn thi bằng Google Gemini (cần tự nhập Gemini API key)

Dữ liệu điểm chỉ lưu trên điện thoại của bạn.
